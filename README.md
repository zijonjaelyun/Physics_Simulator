# 인터랙티브 물리 실험실 — Streamlit

## 실행

Python 3.10 이상을 설치한 후 터미널에서:

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 자동으로 열리지 않으면 http://localhost:8501 에 접속하세요.

## Streamlit Community Cloud 배포

1. GitHub에 `app.py`, `requirements.txt`를 업로드합니다.
2. https://share.streamlit.io/ 에서 **Create app**을 선택합니다.
3. 저장소와 브랜치를 지정하고 Main file path를 `app.py`로 설정합니다.
4. 배포를 시작하면 웹 주소가 생성됩니다.

## 모듈

- 등가속도 직선 운동
- 수직 던지기
- 포물선 운동 (두 입력 모드)
- 1차원 탄성/완전 비탄성 충돌
- 감쇠 없는 비선형 단진자 (RK4 적분)
- 엘리베이터의 겉보기 무게와 관성력
- 원 궤도 및 케플러 관계
- 탈출 속도 및 슈바르츠실트 반지름

## 모델 제한

- 공기저항, 감쇠, 비구면 천체, 다체 중력은 고려하지 않습니다.
- 원 궤도만 계산하며 일반적인 타원 궤도는 아직 구현하지 않았습니다.
- 충돌은 지정 시각의 순간 충돌로 이상화한 시각화입니다.
- 블랙홀 모듈의 원형 그림은 크기 비교 도식이지 실제 입자 궤적이 아닙니다.
- 사용자 제공 공식과 구현용 추가 제안 공식은 앱의 '물리 모델 · 적용 조건'에 구분했습니다.
